{{ if .Values.eval.generateSecrets }}
────────────────────────────────────────────────────────────────────────────────
⚠ THIS RELEASE GENERATED ITS OWN SECRETS. NOT FOR PRODUCTION.

They survive `helm upgrade` only because `lookup` can read them from the live
cluster. `lookup` returns EMPTY under `helm template`, which is how ArgoCD, Flux
and every `helm template | kubectl apply` pipeline render a chart — so syncing
this release through any of them will mint a new SETTINGS_ENC_KEY and make every
stored SSO client secret permanently undecryptable.

Before this instance holds anything real, move to a Secret you control:
  docs/deploy/secret-injection.md
────────────────────────────────────────────────────────────────────────────────
{{- end }}

{{- if .Values.config.exposeApiDocs }}
⚠ EXPOSE_API_DOCS IS ON. /docs and /openapi.json are unauthenticated by
  construction and publish the whole admin surface. Turn it off after the
  support session that needed it.

There is no HA: one replica, Recreate, ReadWriteOnce volumes. The scheduler runs
in-process and migrations run at boot, so a second replica would double every
scheduled scan and race the migration. Plan maintenance windows accordingly.
